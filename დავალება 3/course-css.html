CSS-ის 10 სრული გაკვეთილი

თითოეული გაკვეთილი შეიცავს პრაქტიკულ ნაბიჯებს და დავალებას.

გაკვეთილი 1 — CSS-ის საფუძვლები

ამ გაკვეთილზე გაიგებ, როგორ მუშაობს CSS და როგორ ვუკავშირებთ მას HTML-ს.

  1. შექმენი styles.css ფაილი.
  2. HTML-ის head-ში დაამატე stylesheet.
  3. შექმენი პირველი CSS selector.
  4. შეცვალე ტექსტის ფერი color-ით.
  5. შეცვალე ფონის ფერი background-ით.
  6. შეცვალე ტექსტის ზომა font-size-ით.
  7. შეცვალე ტექსტის სისქე font-weight-ით.
  8. გამოიყენე class selector.
  9. გამოიყენე id selector.
  10. შექმენი პატარა styled card.

პრაქტიკული დავალება: შექმენი HTML card და CSS-ით შეცვალე მისი ფერი, ზომა და typography.

გაკვეთილი 2 — CSS Variables

ისწავლი CSS Custom Properties-ს და მათ გამოყენებას Design System-ში.

  1. შექმენი :root.
  2. შექმენი --primary variable.
  3. შექმენი --background.
  4. შექმენი --text.
  5. გამოიყენე var().
  6. შეცვალე button-ის ფერი variable-ით.
  7. შეცვალე body-ის ფონი.
  8. შექმენი spacing variable.
  9. შექმენი border-radius variable.
  10. შექმენი პატარა CSS Design System.

პრაქტიკული დავალება: შექმენი მინიმუმ 5 CSS variable და გამოიყენე ისინი მთელ გვერდზე.

გაკვეთილი 3 — Box Model

გაიგებ content, padding, border და margin-ის განსხვავებას.

  1. შექმენი div.
  2. მიუთითე width.
  3. მიუთითე height.
  4. დაამატე padding.
  5. დაამატე border.
  6. დაამატე margin.
  7. გამოიყენე box-sizing: border-box.
  8. შეადარე content-box და border-box.
  9. შექმენი card layout.
  10. სწორად დაარეგულირე spacing.

პრაქტიკული დავალება: შექმენი პროდუქტის card padding, border და margin-ის გამოყენებით.

გაკვეთილი 4 — Flexbox

Flexbox გამოიყენება ელემენტების ერთგანზომილებიანი განლაგებისთვის.

  1. შექმენი flex container.
  2. გამოიყენე display: flex.
  3. გამოიყენე flex-direction.
  4. გამოიყენე justify-content.
  5. გამოიყენე align-items.
  6. გამოიყენე gap.
  7. გამოიყენე flex-wrap.
  8. შექმენი navigation.
  9. შექმენი button group.
  10. შექმენი responsive flex layout.

პრაქტიკული დავალება: შექმენი navigation bar Flexbox-ის გამოყენებით.

გაკვეთილი 5 — CSS Grid

CSS Grid საშუალებას გაძლევს შექმნა რთული ორნაირი მიმართულების layout.

  1. შექმენი grid container.
  2. გამოიყენე display: grid.
  3. განსაზღვრე columns.
  4. გამოიყენე grid-template-columns.
  5. გამოიყენე gap.
  6. შექმენი სამი card.
  7. გამოიყენე repeat().
  8. გამოიყენე minmax().
  9. შექმენი responsive grid.
  10. შექმენი სრული course catalog.

პრაქტიკული დავალება: შექმენი 6 კურსის card CSS Grid-ის გამოყენებით.

გაკვეთილი 6 — Responsive Design

ისწავლი როგორ მოარგო ვებგვერდი სხვადასხვა ეკრანის ზომას.

  1. გამოიყენე viewport meta tag.
  2. შექმენი mobile-first layout.
  3. გამოიყენე max-width.
  4. გამოიყენე min-width.
  5. შექმენი media query.
  6. დაამატე mobile breakpoint.
  7. დაამატე tablet breakpoint.
  8. შეცვალე grid columns.
  9. შეცვალე navigation.
  10. შეამოწმე გვერდი ტელეფონზე.

პრაქტიკული დავალება: შექმენი responsive portfolio რომელიც სწორად მუშაობს mobile, tablet და desktop-ზე.

გაკვეთილი 7 — Pseudo-classes

შეისწავლი hover, focus, checked, valid და სხვა CSS მდგომარეობებს.

  1. გამოიყენე :hover.
  2. გამოიყენე :focus.
  3. გამოიყენე :active.
  4. გამოიყენე :checked.
  5. გამოიყენე :valid.
  6. გამოიყენე :invalid.
  7. შექმენი hover button.
  8. შექმენი CSS-only checkbox.
  9. შექმენი CSS-only filter.
  10. გამოიყენე :has() theme-ისთვის.

პრაქტიკული დავალება: შექმენი CSS-only navigation ან filter system.

გაკვეთილი 8 — Transform და Hover Effects

ისწავლი CSS transform-სა და interactive hover ეფექტებს.

  1. გამოიყენე transform.
  2. გამოიყენე translateY().
  3. გამოიყენე scale().
  4. გამოიყენე rotate().
  5. შექმენი card hover.
  6. დაამატე shadow.
  7. დაამატე image scale.
  8. გამოიყენე transition.
  9. შექმენი 3D card effect.
  10. შეამოწმე reduced-motion რეჟიმი.

პრაქტიკული დავალება: შექმენი კურსის card, რომელიც hover-ზე ოდნავ აიწევა და გადიდდება.

გაკვეთილი 9 — CSS Animations

ისწავლი keyframes, animation და smooth transitions.

  1. შექმენი @keyframes.
  2. განსაზღვრე from მდგომარეობა.
  3. განსაზღვრე to მდგომარეობა.
  4. გამოიყენე animation-name.
  5. გამოიყენე animation-duration.
  6. გამოიყენე animation-iteration-count.
  7. შექმენი floating animation.
  8. შექმენი loading animation.
  9. გამოიყენე transition hover-ზე.
  10. დაამატე prefers-reduced-motion.

პრაქტიკული დავალება: შექმენი ანიმირებული hero card მხოლოდ CSS-ის გამოყენებით.

Course Lessons

JavaScript-ის 10 სრული გაკვეთილი

თითოეული გაკვეთილი შეიცავს პრაქტიკულ ნაბიჯებს, მაგალითებს და საბოლოო დავალებას.

გაკვეთილი 1 — JavaScript-ის საფუძვლები

ამ გაკვეთილზე გაიგებ, რა არის JavaScript, სად გამოიყენება და როგორ ვამატებთ მას HTML-ში.

  1. შექმენი ახალი HTML ფაილი.
  2. შექმენი <script> ელემენტი.
  3. დაწერე პირველი JavaScript კოდი.
  4. გამოიყენე console.log().
  5. გახსენი browser console.
  6. გამოიტანე ტექსტი console-ში.
  7. გამოიტანე რიცხვი console-ში.
  8. შეადარე JavaScript და HTML.
  9. შექმენი ცალკე .js ფაილი.
  10. HTML-ს დაუკავშირე JavaScript ფაილი.

პრაქტიკული დავალება: შექმენი HTML გვერდი, რომელიც დაკავშირებულია ცალკე JavaScript ფაილთან და console-ში გამოაქვს შენი სახელი და სასწავლო მიზანი.

გაკვეთილი 2 — Variables და Data Types

ისწავლი მონაცემების შენახვას variables-ში და გაიგებ JavaScript-ის ძირითად მონაცემთა ტიპებს.

  1. შექმენი let variable.
  2. შექმენი const variable.
  3. ისწავლე var-ის დანიშნულება.
  4. შეინახე string.
  5. შეინახე number.
  6. შექმენი boolean მნიშვნელობა.
  7. გამოიყენე null.
  8. შეამოწმე მნიშვნელობის ტიპი typeof-ით.
  9. შეცვალე let variable-ის მნიშვნელობა.
  10. შექმენი პატარა user მონაცემების ობიექტი.

პრაქტიკული დავალება: შექმენი ცვლადები, რომლებიც ინახავს სტუდენტის სახელს, ასაკს, დონეს და კურსის სტატუსს.

გაკვეთილი 3 — Operators და Conditions

ისწავლი როგორ შეასრულო გამოთვლები და როგორ მიიღოს პროგრამამ გადაწყვეტილება.

  1. გამოიყენე addition operator.
  2. გამოიყენე subtraction.
  3. გამოიყენე multiplication.
  4. გამოიყენე division.
  5. გამოიყენე comparison operators.
  6. შეადარე ორი რიცხვი.
  7. შექმენი if statement.
  8. დაამატე else.
  9. გამოიყენე else if.
  10. შექმენი ასაკის შემოწმების პროგრამა.

პრაქტიკული დავალება: შექმენი პროგრამა, რომელიც სტუდენტის ქულის მიხედვით გამოიტანს შესაბამის შედეგს.

გაკვეთილი 4 — Loops

Loop-ები საშუალებას გაძლევს ერთი და იგივე ოპერაცია რამდენჯერმე შეასრულო.

  1. გაიგე რა არის loop.
  2. შექმენი for loop.
  3. შექმენი counter.
  4. შეცვალე loop-ის საწყისი მნიშვნელობა.
  5. გამოიყენე loop პირობით.
  6. შექმენი while loop.
  7. შეაჩერე loop სწორი პირობით.
  8. გამოიყენე break.
  9. გამოიყენე continue.
  10. დაბეჭდე 1-დან 100-მდე რიცხვები.

პრაქტიკული დავალება: შექმენი პროგრამა, რომელიც 1-დან 100-მდე გამოიტანს მხოლოდ ლუწ რიცხვებს.

გაკვეთილი 5 — Functions

Functions გამოიყენება კოდის დასაყოფად და მრავალჯერადი გამოყენებისთვის.

  1. შექმენი პირველი function.
  2. გამოიძახე function.
  3. დაამატე parameter.
  4. გადასცი argument.
  5. გამოიყენე return.
  6. შექმენი ორი რიცხვის დამამატებელი function.
  7. შექმენი ტექსტის დასაბრუნებელი function.
  8. შექმენი arrow function.
  9. შეადარე ჩვეულებრივი და arrow function.
  10. შექმენი reusable utility function.

პრაქტიკული დავალება: შექმენი function, რომელიც მიიღებს სტუდენტის სახელსა და ქულას და დააბრუნებს შედეგს.

გაკვეთილი 6 — Arrays

Arrays გამოიყენება რამდენიმე მნიშვნელობის ერთ მონაცემთა სტრუქტურაში შესანახად.

  1. შექმენი პირველი array.
  2. დაამატე რამდენიმე string.
  3. დაამატე numbers.
  4. გამოიყენე array index.
  5. შეცვალე array ელემენტი.
  6. გამოიყენე push().
  7. გამოიყენე pop().
  8. გამოიყენე shift().
  9. გამოიყენე unshift().
  10. გადაუარე array-ს loop-ის გამოყენებით.

პრაქტიკული დავალება: შექმენი კურსების array და loop-ის გამოყენებით გამოიტანე ყველა კურსის სახელი.

გაკვეთილი 7 — Objects

Objects საშუალებას გაძლევს დაკავშირებული მონაცემები key/value სტრუქტურით შეინახო.

  1. შექმენი object.
  2. დაამატე name property.
  3. დაამატე age property.
  4. დაამატე course property.
  5. წაიკითხე property.
  6. შეცვალე property.
  7. დაამატე ახალი property.
  8. წაშალე property.
  9. შექმენი object method.
  10. შექმენი სტუდენტის სრული object.

პრაქტიკული დავალება: შექმენი student object, რომელსაც ექნება სახელი, კურსი, დონე, ქულა და სასწავლო სტატუსი.

გაკვეთილი 8 — DOM

DOM-ის დახმარებით JavaScript-ს შეუძლია HTML დოკუმენტის ელემენტების მოძებნა და შეცვლა.

  1. გაიგე რა არის DOM.
  2. გამოიყენე document.
  3. გამოიყენე getElementById().
  4. გამოიყენე querySelector().
  5. შეცვალე ელემენტის ტექსტი.
  6. შეცვალე HTML content.
  7. შეცვალე CSS style JavaScript-ით.
  8. დაამატე class.
  9. წაშალე class.
  10. შექმენი მარტივი DOM interaction.

პრაქტიკული დავალება: შექმენი HTML card და JavaScript-ით შეცვალე მისი ტექსტი და სტილი.

გაკვეთილი 9 — Events და Interactive UI

Events საშუალებას აძლევს ვებგვერდს რეაგირება მოახდინოს მომხმარებლის მოქმედებებზე.

  1. გაიგე რა არის event.
  2. გამოიყენე click event.
  3. გამოიყენე mouse events.
  4. გამოიყენე keyboard event.
  5. გამოიყენე addEventListener().
  6. შექმენი button interaction.
  7. შეცვალე ტექსტი click-ზე.
  8. შეცვალე class click-ზე.
  9. შექმენი მარტივი counter.
  10. შექმენი interactive card.

პრაქტიკული დავალება: შექმენი ღილაკი, რომელიც დაჭერისას ცვლის გვერდის ტექსტს და ამატებს CSS class-ს.

გაკვეთილი 10 — Final JavaScript Project

საბოლოო პროექტში გამოიყენებ კურსის განმავლობაში ნასწავლ ყველა ძირითად JavaScript ტექნიკას.

  1. შექმენი HTML სტრუქტურა.
  2. შექმენი CSS დიზაინი.
  3. შექმენი JavaScript ფაილი.
  4. შექმენი variables.
  5. შექმენი functions.
  6. გამოიყენე arrays.
  7. გამოიყენე objects.
  8. დაამატე DOM manipulation.
  9. დაამატე user events.
  10. შექმენი სრულფასოვანი interactive project.

Final Project: შექმენი პატარა „Course Tracker“, სადაც მომხმარებელი შეძლებს კურსების ნახვას, არჩევას და პროგრესის ჩვენებას.

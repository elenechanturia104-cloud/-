HTML-ის 10 გაკვეთილი

გაკვეთილი 1 — HTML დოკუმენტის საფუძველი

ამ გაკვეთილზე შეისწავლი HTML დოკუმენტის ძირითად სტრუქტურას.

  1. შექმენი ახალი ფაილი index.html.
  2. დაამატე <!DOCTYPE html>.
  3. შექმენი <html>.
  4. მიუთითე lang="ka".
  5. შექმენი <head>.
  6. დაამატე <title>.
  7. შექმენი <body>.
  8. დაამატე პირველი <h1>.
  9. დაამატე პირველი paragraph.
  10. გახსენი ფაილი ბრაუზერში და შეამოწმე შედეგი.

პრაქტიკული დავალება: შექმენი საკუთარი პირველი HTML გვერდი.

გაკვეთილი 2 — სათაურები და ტექსტი
  1. გამოიყენე h1.
  2. დაამატე h2.
  3. შექმენი paragraph.
  4. გამოიყენე strong.
  5. გამოიყენე em.
  6. შექმენი unordered list.
  7. შექმენი ordered list.
  8. დაამატე ტექსტური ელემენტები.
  9. დაალაგე heading hierarchy.
  10. შექმენი პატარა სტატია.

პრაქტიკული დავალება: დაწერე სტატია „რატომ უნდა ვისწავლოთ პროგრამირება?“

გაკვეთილი 3 — Semantic HTML
  1. დაამატე header.
  2. შექმენი nav.
  3. დაამატე main.
  4. შექმენი section.
  5. დაამატე article.
  6. დაამატე aside.
  7. შექმენი footer.
  8. მოაწესრიგე headings.
  9. შეამოწმე HTML სტრუქტურა.
  10. div-ების ნაწილი semantic ელემენტებით შეცვალე.
გაკვეთილი 4 — Links
  1. შექმენი anchor.
  2. დაამატე href.
  3. დააკავშირე მეორე HTML გვერდი.
  4. შექმენი შიდა ბმული.
  5. გამოიყენე id.
  6. შექმენი navigation.
  7. დაამატე დაბრუნების ღილაკი.
  8. შეამოწმე ყველა ბმული.
  9. გამოიყენე descriptive ტექსტი.
  10. შექმენი პატარა multi-page website.
გაკვეთილი 5 — Images და Figure
  1. დაამატე img.
  2. მიუთითე src.
  3. დაამატე meaningful alt.
  4. შექმენი figure.
  5. დაამატე figcaption.
  6. დაამატე მეორე სურათი.
  7. შეამოწმე alt ტექსტი.
  8. შექმენი responsive image.
  9. დაამატე image card.
  10. შექმენი პატარა gallery.
გაკვეთილი 6 — HTML Forms
  1. შექმენი form.

  3. დაამატე text input.
  4. დაამატე email input.
